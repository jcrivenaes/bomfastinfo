rclone-hordfast

rclone-hordfast is a private OAuth client used by the owner of this site to access the owner's own Google Drive from personal Linux computers using rclone. The Bomfast site is mainly about Hordfast.

The application is not offered as a public service and is not intended for use by other users.

Google Drive access is used only for reading, writing and managing files in the owner's own Google Drive account.
